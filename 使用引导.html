🚀 WeChat Content Studio

公众号内容创作全流程 · 傻瓜式使用指南

这是什么？

这是一个帮你自动写公众号的工具。你只需要说一句话，它就能帮你：

  • 写文章初稿
  • 生成标题候选
  • 生成封面图和配图
  • 自动排版
  • 上传到公众号草稿箱

注意：只上传草稿箱，绝不自动发布，发布永远你自己点。

准备工作（一次性）

1

准备好你的公众号凭证

登录 微信公众平台，然后：

左下角「设置与开发」→「基本配置」，找到：
• AppID（wx开头的一串）
• AppSecret（点「重置」生成）

2

把你的IP加到白名单

在同一个页面，找到「IP白名单」，点「修改」，把你的公网IP加进去。

💡 怎么查我的IP？
运行这个命令就能看到：
python upload_to_draft.py --config config.json --check-ip
3

填配置文件

打开 scripts/config.json，把你的AppID和AppSecret填进去：

{
  "appid": "你的AppID",
  "appsecret": "你的AppSecret"
}
⚠️ 注意
config.json 包含你的密钥，不要提交到Git，也不要发给别人。

三步上手（每次用）

1

跟豆包说一句话

打开豆包，跟它说：
"帮我写一篇关于XX的公众号文章，上传到草稿箱"

比如：
"帮我写一篇关于怎么用AI做会议纪要的公众号文章，上传到草稿箱"

2

等它做完

豆包会自动帮你：
• 写文章
• 生成标题候选（你选一个）
• 生成封面和配图
• 排版
• 上传到草稿箱

3

去公众号后台检查

登录微信公众平台 → 草稿箱，看看排版对不对，预览一下，没问题就手动点发布。

常见问题

Q：报错"IP不在白名单"怎么办？
运行 python upload_to_draft.py --config config.json --check-ip 看你的IP，然后把这个IP加到公众号后台的白名单里。
Q：报错"AppSecret错误"怎么办？
去公众号后台「基本配置」里重新生成一个AppSecret，然后填到config.json里。
Q：排版不好看怎么办？
跟豆包说"换一个排版风格"，它会帮你换另一套模板。一共有8套不同风格的模板。
Q：文章内容不满意怎么办？
直接跟豆包说"把第三段改得口语化一点"、"标题再劲爆一点"，它会帮你改。
Q：图片有乱码怎么办？
跟豆包说"图片有乱码，重新生成一张"，它会重新生成。这个问题已经在底层修复了，一般不会出现。

注意事项

⚠️ 重要提醒
  • 只上传草稿，绝不自动发布——发布动作永远你自己点
  • 发布前一定要预览一遍，看看排版对不对
  • 检查人名、数字、时间节点有没有错
  • config.json 不要发给别人，不要提交到Git
