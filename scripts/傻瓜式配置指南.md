# 傻瓜式配置指南

## 只需要填两个东西，其他都不用管

---

## 第一步：拿到你的 AppID 和 AppSecret

1. 登录微信公众平台：https://mp.weixin.qq.com
2. 左下角点「设置与开发」→「基本配置」
3. 复制 **AppID**（wx 开头的一串字符）
4. 点「重置」生成 **AppSecret**（只显示一次，立即复制）

---

## 第二步：填进配置文件

打开 `config.json`，把两个东西填进去：

```json
{
  "appid": "wx你的AppID填这里",
  "appsecret": "你的AppSecret填这里"
}
```

就这么简单！

---

## 第三步：配 IP 白名单

1. 在同一个页面往下滑，找到「IP 白名单」
2. 点「修改」
3. 把你当前的公网 IP 填进去

**怎么看我的公网 IP？**

运行这个命令，一键就能看到：
```bash
python upload_to_draft.py --config config.json --check-ip
```

它会直接告诉你当前公网 IP 是什么，复制粘贴到白名单里就行。

---

## 第四步：开始用

配置好之后，直接说「帮我写一篇关于XX的公众号文章」就行，其他都不用管。

---

## 常见问题

### 问：为什么要配 IP 白名单？
答：微信 API 的安全要求，必须白名单里的 IP 才能调用。

### 问：我家宽带是动态 IP 怎么办？
答：每次 IP 变了重新加一下就行，或者加一个网段（比如 `192.168.1.0/24`）。

### 问：config.json 会泄露吗？
答：不会，已经在 .gitignore 里排除了，不会传到 GitHub。
