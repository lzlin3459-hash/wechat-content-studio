## 🎯 这是什么

> **不是又一个写作工具，而是一套完整的内容操作系统。**

`WeChat Content Studio` 把公众号创作的经验沉淀为**六步标准化流水线**——从定位、选题、写作、标题封面、配图排版到数据复盘，每一步都有可复用的提示词模板、排版主题和决策红线，并内置微信公众号草稿箱上传脚本，实现**从灵感到草稿箱的一站式闭环**。

核心方法论只有一句话：

> **人定骨架，AI 填肉。**
> 观点、结构、情绪节奏由人定；补全、执行、排版交给 AI。

## ✨ 核心特性

| 特性 | 说明 |
|---|---|
| 🧭 **六步流水线** | 定位 → 选题 → 写作 → 标题封面 → 配图排版 → 复盘，每一步都有明确决策树和止损红线 |
| 📝 **7 套提示词模板** | 定位 / 选题分析 / 完形填空写作 / 活人审核 / 标题批量生成 / 封面构图 / 数据复盘，复制即用 |
| 🎨 **6 套去AI味排版主题** | 杂志 / 商务 / 文艺 / 极客 / 治愈 / 干货，内联样式、编辑器友好，一键粘贴公众号 |
| 📊 **数据复盘闭环** | 选题池 / 标题库 / 文章表现库字段设计，红绿灯自动判定，让系统越用越懂你的读者 |
| 📮 **草稿箱一键上传** | 内置微信公众号 API 脚本：获取 token → 上传封面 → 写入草稿箱，不自动发布、保留人工审核 |
| 🛡️ **红线思维** | 每一步都有预算和止损线——3 天无爆款换赛道、单篇 ≤3 小时、打开率 <5% 复盘标题 |

## 🚀 快速开始

### 3 分钟上手

```bash
# 1. 克隆仓库
git clone https://github.com/<your-username>/wechat-content-studio.git
cd wechat-content-studio

# 2. 阅读创作 SOP（内容创作板块/00_内容创作SOP总览.md）

# 3. 按提示词模板（内容创作板块/01_创作指令包.md）开始第一篇创作
```

### 接入草稿箱（可选）

```bash
# 1. 复制配置模板，填入你的公众号 AppID / AppSecret
cp scripts/config.example.json scripts/config.json

# 2. 编辑 config.json，填入凭证（⚠️ 不要提交到 Git）

# 3. 一键上传草稿
python scripts/upload_to_draft.py \
    --config scripts/config.json \
    --title "文章标题" \
    --author "作者" \
    --digest "文章摘要" \
    --content-html "./article.html" \
    --cover-image "./cover.png"
```

> 📌 **前置条件**：在微信公众平台「设置与开发 → 基本配置」中，把运行机器的公网 IP 加入 **IP 白名单**。详见 `scripts/README-上传脚本.md`。
