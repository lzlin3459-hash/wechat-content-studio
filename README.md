## 🎯 这是什么

> **不是又一个写作工具，而是一套完整的内容操作系统。**

`WeChat Content Studio` 把公众号创作的经验沉淀为**六步标准化流水线**——从定位、选题、写作、标题封面、配图排版到数据复盘，每一步都有可复用的提示词模板、排版主题和决策红线，并内置微信公众号草稿箱上传脚本，实现**从灵感到草稿箱的一站式闭环**。

核心方法论只有一句话：

> **人定骨架，AI 填肉。**
> 观点、结构、情绪节奏由人定；补全、执行、排版交给 AI。

## 🚀 快速开始

### 傻瓜式配置（只需要做一次）

**第一步：填两个东西**

打开 `scripts/config.json`，填入你的微信公众号信息：

```json
{
  "appid": "wx你的AppID填这里",
  "appsecret": "你的AppSecret填这里"
}
```

**怎么拿 AppID 和 AppSecret？**
1. 登录 https://mp.weixin.qq.com
2. 左下角「设置与开发」→「基本配置」
3. 复制 AppID，点重置生成 AppSecret

**第二步：配 IP 白名单**
- 在同一个页面往下滑，找到「IP 白名单」
- 把你当前的公网 IP 加进去
- 不知道自己 IP？运行脚本报 40164 错误时会告诉你

---

### 开始用

配置好之后，直接说：

> 「帮我写一篇关于XX的公众号文章」

剩下的都不用管，AI 会自动帮你：
- 选题 → 写文章 → 起标题 → 生成封面 → 配图 → 排版 → 上传草稿箱
