# 公众号内容创作 SOP（豆包版）

> 依据：[情报206]公众号10大Skill创作全流程 + [情报241]开源公众号排版Skill去AI味
> 定位：以豆包为底座的标准化内容流水线。**人定骨架，AI填肉**——观点、结构、情绪节奏由人定，AI负责补全与执行。

---

## 核心公式

```
公众号爆款 = 真实需求选题 × 高情绪标题 × 安全区封面 × 稳定更新
时间投入：50% 选题 / 30% 标题封面 / 20% 行文
去AI味 = 预设模板 + 流程编排 + 人工微调
```

---

## 六步流水线

| 步骤 | 目标 | 豆包执行内容 | 输出 | 决策点 / 止损线 |
|---|---|---|---|---|
| ① 定位 | 一句话收敛定位 | 用定位问题集收敛，生成简介/关注回复/菜单三件套 | 定位句 + 三件套 | 定位不清 → 先对标5个同行抄作业再优化 |
| ② 选题 | 数据驱动选题 | 赛道关键词扫描 + 低粉高阅读探测 | 选题候选表（含评分） | **连续3天找不到3个爆款候选 → 立即换关键词赛道** |
| ③ 写作 | 完形填空法成稿 | 长文六种写法 / 短文去AI腔 + 活人审核 | 初稿 + 审核报告 | 单篇（含修改）≤3小时，超时收手 |
| ④ 标题封面 | 高情绪标题 + 安全区封面 | 批量生成15-20个候选，逐条评分标注风险 | 2-3个最佳标题 + 封面图 | 发布24h打开率<5% → 复盘标题封面，下次迭代 |
| ⑤ 配图排版 | 图文并茂 + 无AI味 | 按段落中心意思生成配图 + 主题化HTML排版 | 可粘贴的公众号HTML | 快速发布可跳过配图；排版后必须真机预览 |
| ⑥ 复盘分发 | 数据沉淀 + 二次分发 | 汇总阅读/在看/涨粉数据，更新选题与标题库 | 复盘周报 + 红绿灯 | 连续2周红灯 → 强制启动选题方向大复盘 |

---

## 决策树

```
开始创作
├─ 有明确赛道关键词？ ──否──> 先做 ②选题 关键词扫描，3天内无爆款候选即换道
├─ 图文并茂？ ──是──> 先配图（图表/逻辑图/插画）再排版
├─ 快速发布？ ──是──> 跳过配图，纯文字排版
├─ 品牌调性明确？ ──是──> 用主题生成器/自定义CSS
├─ 无设计能力？ ──是──> 先用内置6套主题
└─ 排版完成 ──> 真机预览 → 人工微调 → 进草稿箱
```

---

## 时间预算（红线）

| 环节 | 预算 | 超时处理 |
|---|---|---|
| 选题 | 每天 30 分钟（定时任务自动扫描） | 3天无产出即换赛道 |
| 写作（含修改） | 单篇 ≤ 3 小时 | 立即收手，用占位符留骨架 |
| 标题封面 | 30 分钟（批量生成+人工选改） | 只选2-3个最佳，不追求完美 |
| 配图排版 | 30-60 分钟 | 单篇排版>30分钟退回人工手排 |
| 复盘 | 每周 30 分钟 | 红绿灯自动判定 |

---

## 执行边界（避坑）

1. **人定骨架不可外包**：个人经历、反常识观点、独特案例是硬边界，AI不能替你想。
2. **草稿躺2天**：写完后进草稿箱躺两天，第二天朗读检查再发。
3. **发布保留人工确认**：豆包只负责产出内容，发布动作由人触发。
4. **内容同质化防御**：AI填肉可复制，骨架不可复制——把"我的经历/观点"作为每次创作的前置输入。
