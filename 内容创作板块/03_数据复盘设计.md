# 数据复盘设计（内容流水线台账）

> 用途：沉淀选题、标题、文章表现三类数据，形成**可迭代的决策树**——每次创作都让下一次更准。
> 后续形态：可直接迁移为飞书多维表格（lark-base）或本地表格。

---

## 1. 账号档案表（一次性填写，每次创作引用）

| 字段 | 示例 | 说明 |
|---|---|---|
| 一句话定位 | AI办公效率教练 | 来自定位指令 |
| 赛道关键词 | AI办公 / 自动化 / 效率工具 | 选题扫描的基础 |
| 目标读者 | 职场白领 / 中小企业主 | 写作语气依据 |
| 个人独特价值 | 5年运营操盘经验 | "人定骨架"的来源 |
| 对标账号 | 5个 | 抄作业再优化 |
| 禁写主题 | 医疗荐药 / 敏感时政 | 红线 |

## 2. 选题池（每个候选一条记录）

| 字段 | 说明 |
|---|---|
| 选题名称 | 一句话 |
| 来源 | 关键词扫描 / 低粉高阅读探测 / 用户提问 / 灵感 |
| 赛道关键词 | 所属赛道 |
| 爆款潜力评分（1-10） | 豆包评分 + 人工复核 |
| 风险标注 | 标题党风险 / 平台审核风险 |
| 状态 | 待写 → 写作中 → 已发布 → 已放弃 |
| 关联文章标题 | 发布后回填 |
| 实际表现 | 发布后回填（打开率/阅读/在看） |

**止损规则**：连续 3 天新增爆款潜力 ≥7 的选题不足 3 个 → 换关键词赛道。

## 3. 标题表现库（每个候选标题一条记录）

| 字段 | 说明 |
|---|---|
| 标题原文 | 完整标题 |
| 所属文章 | 关联 |
| 风格标签 | 悬念/数字/反常识/身份共鸣/场景代入 |
| 情绪强度（1-10） | 生成时评分 |
| 风险（1-10） | 生成时评分 |
| 是否选用 | 是/否 |
| 24h打开率 | 发布后回填 |

**迭代规则**：连续多篇低打开率（<5%）→ 复盘标题风格分布，找出用户真正点击的类型；高打开率标题风格加权。

## 4. 文章表现库（发布后一条记录）

| 字段 | 说明 |
|---|---|
| 标题 / 选题 | 双字段回填 |
| 发布时间 | 精确到小时 |
| 阅读量 / 在看 / 点赞 | 后台数据 |
| 涨粉数 | 后台数据 |
| 24h打开率 | 群发后核心指标 |
| 单粉报价参考 | 粉丝量 ×0.5~1 元（接商单时用） |
| 复盘结论 | 爆款/扑街原因一句话 |
| 红绿灯 | 绿/黄/红 |

## 5. 红绿灯规则（每周判定）

| 指标 | 绿灯 | 黄灯 | 红灯 |
|---|---|---|---|
| 24h打开率 | ≥8% | 5-8% | <5% |
| 周涨粉 | ≥50 | 10-50 | <10 |
| 单粉报价 | 达标 | 偏低 | 远低于粉丝×0.5元 |

**强制动作**：连续 2 周红灯 → 启动"选题方向大复盘"（重做定位、换赛道、重测标题风格）。

---

## 每周复盘流程（30分钟）

1. 豆包汇总本周数据 → 计算环比 → 填表
2. 豆包输出爆款/扑街共性差异（选题/标题/封面/发布时间四维）
3. 更新选题池评分与标题风格权重
4. 输出红绿灯判定 + 下周 3 个选题建议
5. 人工确认 → 写入台账

> 台账是"内容操作系统"的记忆层：AI 的每篇产出、每个数据点都回流到这里，让系统越用越懂你的读者。
