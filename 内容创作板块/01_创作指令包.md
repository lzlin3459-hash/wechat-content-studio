# 创作指令包（可直接粘贴给豆包使用）

> 用法：每个环节把指令模板复制给豆包，替换【】中的参数即可。
> 设计原则：**人定骨架，AI填肉**——所有模板都保留"你提供观点/经历"的入口，AI只做补全与执行。

---

## ① 定位指令

```
请作为公众号定位顾问，基于以下信息帮我收敛定位：
- 我想写：______（领域）
- 目标读者：______（人群）
- 我能持续提供的独特价值：______（经历/技能/视角）
- 参考对标账号：______（1-5个）

输出：
1. 一句话定位（<20字，含读者+领域+价值）
2. 公众号简介（50字内）
3. 关注回复语（引导关注后第一句）
4. 底部菜单设计（3个主菜单及子项）
5. 定位是否清晰的判断，若模糊给出3个备选定位
```

## ② 选题分析指令

```
请作为公众号选题分析师，基于以下数据帮我找本周爆款选题：
- 赛道关键词：______（如：AI办公 / 职场效率）
- 近7天观察到的数据或文章：______（可粘贴标题/阅读数）
- 我的账号优势：______

执行：
1. 扫描赛道关键词，列出3-5个"正在上涨"的话题方向
2. 每个方向给出：选题角度、目标读者痛点、爆款潜力评分（1-10）、风险标注
3. 标注哪些是"黑马选题"（低粉高阅读机会）
4. 若找不到3个潜在爆款选题，明确告诉我"建议换赛道"，并给出3个相邻赛道建议
```

## ③ 完形填空写作指令（长文版）

```
请按"完形填空法"帮我完成这篇公众号长文：

【我的骨架（人定）】
- 主题：______
- 核心观点：______
- 我想讲的故事/案例：______
- 结构安排（起承转合）：______

【执行要求】
1. 先问我2-3个补全素材所需的问题（如果我已给全素材则跳过）
2. 从以下六种写法中匹配最合适的：经验复盘 / 观点输出 / 教程干货 / 案例拆解 / 故事叙事 / 行业洞察
3. 按我的骨架填肉，保持我的语气，不发明新观点
4. 每段有明确中心意思，节奏有起伏（长短句交替）
5. 结尾给出可执行的行动建议
6. 输出后附"信息增益自查"：本文是否包含读者在其他地方看不到的信息？
```

## ③b 完形填空写作指令（短文版）

```
请帮我写一篇公众号短文（800-1500字）：
- 主题：______
- 我的观点/经历：______
- 目标读者：______

要求：
1. 开头3句内抓住注意力
2. 去AI腔检查：禁用"首先/其次/最后""总而言之""值得注意的是"等AI惯用语；禁用无意义的emoji堆砌
3. 有思考、有节奏起伏、有信息增益
4. 结尾一句点题金句
```

## ③c 活人审核指令

```
请以"真人读者"视角审核这篇初稿（粘贴文章），从三个维度打分（1-10）并给出修改建议：
1. 是否有思考（观点是否成立、有无逻辑漏洞）
2. 节奏起伏（是否平铺直叙、有无记忆点）
3. 信息增益（读者是否能获得别处没有的信息）
若某维度<6分，必须给出具体改写方案，而不是只给结论。
```

## ④ 标题批量生成指令

```
请基于这篇文章（粘贴标题+摘要）生成15-20个候选标题：
1. 覆盖5种风格：悬念 / 数字 / 反常识 / 身份共鸣 / 场景代入
2. 每个标题标注：情绪强度（1-10）、点击吸引力（1-10）、风险（标题党程度、平台审核风险）
3. 剔除：夸大虚假、低俗、蹭敏感热点
4. 最后推荐3个最佳，并说明各自适用场景（如：朋友圈转发/搜索流量/群发打开率）
```

## ④b 封面构图指令

```
请为公众号封面设计构图方案：
- 标题：______
- 风格：______（与文章调性一致）

要求：
1. 按 2.35:1 横版比例设计，重要文字/主体放在安全区（中间约60%区域），避免被裁切
2. 主体突出，背景简洁，配色克制（≤3色）
3. 输出构图描述 + 文案排版建议 + 配色方案（色值）
```

## ⑥ 复盘指令

```
请帮我做本周公众号数据复盘：
- 本周文章数据（粘贴：标题/阅读/在看/涨粉/打开率）
- 上周对比数据：______

执行：
1. 计算各指标环比变化
2. 找出爆款与扑街的共性差异（选题/标题/封面/发布时间）
3. 更新选题库评分：哪些赛道被验证，哪些应降权
4. 输出红绿灯判定：绿（正常）/ 黄（关注）/ 红（触发选题大复盘，连续2周红灯）
5. 给出下周3个选题建议
```

---

## 使用提醒

- **赛道与账号信息**：① 和 ② 的【参数】建议沉淀到账号档案（见《03_数据复盘设计.md》的账号档案表），每次创作直接引用，不必重复填写。
- **提示词可演进**：每用一次，把效果差的环节反馈进模板（哪个评分维度不准、哪种写法不合适），模板本身也在迭代。
