# 排版主题包（去AI味 · 6套主题）

> 依据：[情报241]开源公众号排版Skill去AI味
> 核心公式：**去AI味 = 预设模板 + 流程编排 + 人工微调**
> 原理：预设克制主题 → 套用排版 → 真机预览微调；不做花哨样式堆砌。

---

## 使用说明

1. **选择主题**：按文章调性从下表选一套，复制该套的样式参数。
2. **套用模板**：把文章 Markdown 内容填入下方 HTML 模板（标题/引用/列表/加粗处替换）。
3. **一键粘贴**：复制整个 HTML → 公众号编辑器"粘贴为 HTML"。
4. **真机预览**：草稿箱用手机预览，检查：样式是否被过滤、标题是否被裁、间距是否塌陷。
5. **人工微调**：预览后微调（字号、间距、强调色），单篇排版超 30 分钟退回手排。

> ⚠️ 公众号编辑器会过滤部分样式，请以内联 style 为准；发布前必须真机预览。

## 通用 HTML 模板（简约杂志风示例）

```html
<section style="max-width:677px;margin:0 auto;padding:0 12px;font-family:-apple-system,'PingFang SC','Microsoft YaHei',sans-serif;color:#111827;background:#ffffff;font-size:16px;line-height:1.8;letter-spacing:0.2px;">
  <!-- 大标题 -->
  <h1 style="font-size:24px;font-weight:700;line-height:1.4;margin:24px 0 8px;color:#111827;">这里放文章主标题</h1>
  <!-- 副标题/导语 -->
  <p style="font-size:14px;color:#6b7280;margin:0 0 20px;">这里放一句导语，点明文章价值</p>
  <hr style="border:none;border-top:1px solid #e5e7eb;margin:16px 0;">

  <!-- 正文段落 -->
  <p style="margin:12px 0;">这里是正文第一段……</p>

  <!-- 加粗强调 -->
  <p style="margin:12px 0;"><strong style="color:#111827;">金句/关键词：</strong>这里放强调内容</p>

  <!-- 引用 -->
  <blockquote style="margin:20px 0;padding:12px 16px;border-left:4px solid #111827;background:#f9fafb;color:#374151;font-size:15px;">这里放引用/案例/反常识观点</blockquote>

  <!-- 小标题 -->
  <h2 style="font-size:19px;font-weight:700;margin:28px 0 10px;color:#111827;">## 小标题</h2>

  <!-- 列表 -->
  <ul style="margin:12px 0;padding-left:24px;">
    <li style="margin:6px 0;">第一点</li>
    <li style="margin:6px 0;">第二点</li>
  </ul>

  <!-- 分隔 -->
  <hr style="border:none;border-top:1px solid #e5e7eb;margin:24px 0;">

  <!-- 结尾 -->
  <p style="margin:16px 0 8px;font-size:15px;color:#374151;">行动建议/结尾金句</p>
  <p style="font-size:13px;color:#9ca3af;margin-top:24px;text-align:center;">— 完 —</p>
</section>
```

### 其他 5 套主题的替换参数

| 元素 | 商务严谨风 | 文艺清新风 | 科技极客风 | 温暖治愈风 | 知识干货风 |
|---|---|---|---|---|---|
| 页面主色 | #1d4ed8 | #0d9488 | #0ea5e9 | #ea580c | #7c3aed |
| 正文色 | #1f2937 | #134e4a | #334155 | #431407 | #3b0764 |
| 引用底色 | #eff6ff | #f0fdfa | #f0f9ff | #fff7ed | #f5f3ff |
| 标题风格 | 带序号 01/02 | 宋体衬线 | 等宽点缀 | 圆角卡片 | 大圆点编号 |
| 正文样式 | 16px/1.8 | 16px/1.9 | 15px/1.75 | 16px/1.85 | 16px/1.8 |

## 主题生成器（自定义品牌主题）

当有明确品牌调性时，按以下参数自定主题，保存为品牌专属主题：

```
主题名：______
主色：#______（占 60% 视觉，用于标题/强调）
辅色：#______（占 30%，用于引用/边框）
背景：#______（占 10%，用于卡片/代码块）
字体：标题（______）/ 正文（______）
标题风格：______（加粗/衬线/带序号/圆点）
间距：段间距 ______px / 行距 ______
特色元素：______（表格/代码块/卡片/时间线）
禁忌：______（如：不用红色、不用圆角等）
```

> 品牌主题库建议建 1 套基础 + 2-3 套变体（日常/活动/专题），避免 6 套通用主题审美疲劳。

## 去AI味排版检查清单（发布前逐项勾选）

**排版层面**
- [ ] 无花哨渐变、无浓重阴影、无满屏彩色
- [ ] 全文颜色 ≤3 种（主色+辅色+中性色）
- [ ] 留白充足：段间距 ≥12px，行距 ≥1.7
- [ ] 标题层级清晰：H1→H2→正文，无错乱
- [ ] 重点用"加粗+引用"双保险，不靠颜色单通道（色弱读者也能读）
- [ ] 图片与段落呼应，图注 ≤13px 灰色

**文字层面（AI腔排查）**
- [ ] 无"首先/其次/最后""总而言之""值得注意的是""不难发现"
- [ ] 无机械排比堆砌，长短句交替
- [ ] 无多余 emoji（每篇 ≤3 个且有意义）
- [ ] 有第一人称视角（"我"的经历/观点），而非上帝视角
- [ ] 有具体数字/案例/细节，而非空泛形容词

**发布前**
- [ ] 草稿箱躺 2 天，第二天朗读检查
- [ ] 手机真机预览（样式过滤、标题裁切、间距塌陷三项重点查）
- [ ] 标题最终确认（打开率 <5% 时复盘标题封面）
